## 🚀 ¿Qué es Verifija?

**Verifija** es nuestra plataforma especializada y de alta disponibilidad desarrollada por **OSYS COMPANY S.A.C.** para la consulta ágil de:
* 📄 **RUC** (Razón social, estado, condición, dirección fiscal y datos tributarios SUNAT).
* 🪪 **DNI** (Nombres y apellidos completos vía RENIEC).
* 💵 **Tipo de Cambio** (Compra y venta oficial al día).
